# Repository image assets

- `hero.png` is illustrative artwork derived from a user-supplied concept with an image-generation tool. It is not scientific data and contains no encoded forecast values.
- `examples/saint-petersburg/` contains model-output snapshots generated by `render-point` for Saint Petersburg from ICON-EU run `2026072206 UTC` using the versions printed in each image.

Runtime images belong below `data/` and are ignored. Only deliberately selected, privacy-reviewed publication examples belong in this directory.
