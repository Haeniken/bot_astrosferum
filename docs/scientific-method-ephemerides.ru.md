## 4.10. Планировочные эфемериды и отображаемые пути светил

Текущий идентификатор эфемерид —
`celestial-observing-ephemerides-jpl-meeus-wgs84-h0-v4`. Он явно входит
в расчётный запрос и ключ кеша Astrodome; worker или архивный dataset с прежним
идентификатором отклоняется, а не переиспользуется.

Небесный слой — отдельный продукт для планирования, который **не входит в
Overall, сиинг, пропускание облаков или метеорологические величины**.
Канонический порядок: Солнце, Луна, Меркурий, Венера, Марс, Юпитер, Сатурн,
Уран, Нептун и Плутон. Земля является местом наблюдателя и поэтому не
показывается как цель. Каждая сохранённая точка вычисляется точно для
соответствующего часа UTC на оси прогноза. Азимут — геодезический, по часовой
стрелке от истинного севера; высота отсчитывается от местного
астрономического горизонта. Пользовательская высота наблюдателя не вводится,
поэтому топоцентрический наблюдатель располагается на референц-эллипсоиде
WGS84 при нулевой высоте. Это положение на эллипсоиде не подменяет ICON HHL.
Общая заявленная область численной применимости:
`1885-01-02 <= t < 2050-01-01`. Суточный запас у нижней границы удерживает
положение Плутона с учётом запаздывания света внутри опубликованного интервала
ряда; верхняя граница не включается. За пределами области расчёт завершается
явным отказом, а не незаметным переключением семейства приближений.

Для Меркурия—Нептуна используются подобранные кеплеровы элементы,
опубликованные [JPL Solar System
Dynamics](https://ssd.jpl.nasa.gov/planets/approx_pos.html). Это
**опубликованное приближение для планирования**, а не замена интегрированной
эфемериде DE. Для юлианской эфемеридной даты `JDE` число юлианских столетий от
J2000 и линейно продолженные элементы равны

```math
T = \frac{JDE-2451545.0}{36525},
\qquad
x(T)=x_0+\dot{x}T.
```

Аргумент перигелия, исправленная средняя аномалия, уравнение Кеплера и
координаты в плоскости орбиты вычисляются как

```math
\omega=\varpi-\Omega,
```

```math
M=L-\varpi+bT^2+c\cos(fT)+s\sin(fT),
```

```math
M=E-e\sin E,
```

```math
x'=a(\cos E-e),
\qquad
y'=a\sqrt{1-e^2}\sin E,
\qquad
z'=0.
```

Поворот JPL на `omega`, наклонение `I` и долготу восходящего узла `Omega`
переводит вектор в эклиптическую систему J2000. Реализация вычитает вектор
барицентра Земля—Луна и выполняет одну итерацию запаздывания света:

```math
\Delta_0=\lVert \mathbf r_p(t)-\mathbf r_{EMB}(t)\rVert,
```

```math
\mathbf r_g(t)=
\mathbf r_p\!\left(t-\frac{\Delta_0}{c}\right)-\mathbf r_{EMB}(t).
```

Таблица JPL задаёт барицентр Земля—Луна, а не центр Земли. Консервативная
верхняя граница их расстояния `5 000 км` и консервативная нижняя граница
геоцентрического расстояния показанных планет `0,25 а. е.` ограничивают этот
вклад в направление величиной

```math
\arcsin\!\left(
\frac{5000\ \mathrm{км}}{0{,}25\times149597870{,}7\ \mathrm{км}}
\right)<0{,}0077\ \mathrm{градуса}.
```

Это явно заявленная часть планировочного приближения, а не скрытая
высокоточная эфемерида Земли.

#### Расстояние, близость в диапазоне модели, радиальное движение и кольца Сатурна

Диагностика расстояния отделена от положения на небе и пригодности условий.
Для Солнца и Луны `D(t)` отсчитывается от центра Земли. Для планет это
расстояние от барицентра Земля—Луна из таблицы JPL до цели с учётом
запаздывания света. Поэтому поле называется `reference_distance_km`
(«опорное расстояние»), а не точным геоцентрическим расстоянием. В Overall оно
не входит.

Проектная шкала близости использует конечное множество всех целых часов UTC в
общей области модели:

```math
\mathcal T_h=\{1885\text{-}01\text{-}02T00{:}00Z+n\,\mathrm{ч}\mid t<2050\text{-}01\text{-}01T00{:}00Z\}.
```

Для каждого тела закреплённые `D_min` и `D_max` получены исчерпывающим
вычислением каждого элемента `T_h` той же версией эфемериды. Если рабочее
расстояние выходит за сохранённый диапазон, результат отклоняется; скрытого
ограничения значений нет. Для точного часа

```math
C(t)=100\frac{D_{\max}-D(t)}{D_{\max}-D_{\min}}\ \%,
\qquad t\in\mathcal T_h.
```

Следовательно, `100%` означает ближайший дискретный час этой приближённой
модели, а `0%` — самый дальний. Это не вероятность, яркость, угловой размер,
физический процент изменения, перицентр/апоцентр или непрерывный глобальный
экстремум. На графике 1 показывается округлённое до целого среднее по точным
часовым точкам, которые входят в конкретный прогноз:

```math
\bar C_N=\mathrm{round}\!\left(\frac{1}{N}\sum_{i=1}^{N}C(t_i)\right),
```

а интерактивная подсказка выбранного часа показывает `C(t)` до сотых процента.
Разница относится только к представлению.

Знаковая радиальная скорость вычисляется центральной разностью длиной один
час; у границ области применяется односторонняя разность:

```math
v_r(t)=\frac{D(t+30\,\mathrm{мин})-D(t-30\,\mathrm{мин})}{3600\,\mathrm{с}}.
```

Единица — `км/с`; `v_r<0` означает приближение, `v_r>0` — удаление, что
совпадает со знаком величины 20 в JPL Horizons. Произвольная зона
«неподвижности» не вводится. Полушаг `30 мин` — численный выбор для почасового
планировочного продукта. Независимые проверки DE441/Horizons на
`2026-08-12T00:00Z` ограничивают в проверенных случаях Марс—Плутон невязку
расстояния `2 000 000 км`, а скорости — `0,08 км/с`. Это регрессионные пределы
планировочной модели, а не гарантия для всех эпох.

Для Сатурна знаковый угол раскрытия колец использует северный полюс IAU в
момент испускания света:

```math
\alpha_p=40.589^\circ-0.036^\circ T,
\qquad
\delta_p=83.537^\circ-0.004^\circ T.
```

```math
B=\arcsin\!\left(\widehat{\mathbf p}_{N}\cdot
\widehat{\mathbf r}_{Saturn\rightarrow EMB}\right).
```

Положительный `B` показывает северную сторону Сатурна по IAU, отрицательный —
южную. Коэффициенты полюса взяты из [отчёта рабочей группы IAU](https://doi.org/10.1007/s10569-017-9805-5),
а знак соответствует [определению высоты наблюдения колец NASA PDS](https://pds.nasa.gov/datastandards/documents/dd/all/current/ch105s175.html).
Независимый контроль по направлению и полюсу Horizons даёт
`-8,98046 градуса` на `2026-08-12`; предел регрессии реализации —
`0,08 градуса`. `B` описывает раскрытие колец, но не полный позиционный угол
колец в плоскости неба.

#### Наблюдательные характеристики

Сервер вычисляет следующие характеристики в каждой точной почасовой точке.
Это справочные планировочные величины, которые не изменяют Overall.
Экваториальные радиусы закреплены по [физическим параметрам JPL Solar System
Dynamics](https://ssd.jpl.nasa.gov/planets/phys_par.html). Для расстояния от
наблюдателя `Delta_obs` и экваториального радиуса тела `R_eq` угловой диаметр
равен

```math
\theta_{diam}=2\arcsin\!\left(\frac{R_{eq}}{\Delta_{obs}}\right).
```

Для планеты `r_p` — гелиоцентрический вектор цели, а `Delta_p` — вектор от
состояния наблюдателя, заданного через барицентр Земля—Луна. Фазовый угол,
освещённая доля диска в процентах и топоцентрическая элонгация от Солнца равны

```math
\alpha=\arccos\!\left(
\frac{(-\mathbf r_p)\mathbin{\cdot}(-\boldsymbol\Delta_p)}
{\lVert\mathbf r_p\rVert\,\lVert\boldsymbol\Delta_p\rVert}
\right),
\qquad
k=50(1+\cos\alpha)\ \%,
```

```math
\epsilon=\arccos\!\left(
\widehat{\mathbf u}_{body}\mathbin{\cdot}
\widehat{\mathbf u}_{Sun}
\right).
```

Для Луны `epsilon` является топоцентрической элонгацией, а фазовый угол
дополнительно использует расстояния наблюдатель—Луна `Delta_M` и
наблюдатель—Солнце `R_S`:

```math
\alpha_M=\arctan2\!\left(
R_S\sin\epsilon,
\Delta_M-R_S\cos\epsilon
\right).
```

Планировочная видимая звёздная величина планет в полосе Johnson V следует
[Mallama и Hilton (2018)](https://arxiv.org/abs/1808.01973). Расстояния `r`
(гелиоцентрическое) и `Delta` (опорное от барицентра Земля—Луна) задаются в
астрономических единицах; вводится общий член

```math
d=5\log_{10}(r\Delta).
```

При фазовом угле `a` в градусах реализованы следующие формулы для земного
наблюдателя:

```math
\begin{aligned}
V_{Mercury}={}&-0.613+d+0.063280a-0.0016336a^2
+3.3644\times10^{-5}a^3\\
&-3.4265\times10^{-7}a^4+1.6893\times10^{-9}a^5
-3.0334\times10^{-12}a^6,\\
V_{Venus}={}&-4.384+d-0.001044a+0.0003687a^2
-2.814\times10^{-6}a^3+8.938\times10^{-9}a^4,
\quad 0<a\le163.7,\\
V_{Venus}={}&236.05828+d-2.81914a+0.00839034a^2,
\quad 163.7<a<179,\\
V_{Mars}={}&-1.601+d+0.02267a-0.0001302a^2,
\quad 0\le a\le50,\\
V_{Mars}={}&-0.367+d-0.02573a+0.0003445a^2,
\quad 50<a\le180,\\
V_{Jupiter}={}&-9.395+d-0.00037a+0.000616a^2,
\quad 0\le a\le12.
\end{aligned}
```

При большем фазовом угле Юпитера `x=a/180` и

```math
P_J(x)=1-1.507x-0.363x^2-0.062x^3+2.809x^4-1.876x^5,
```

```math
V_{Jupiter}=-9.428+d-2.5\log_{10}P_J(x),
\qquad 12<a<130.
```

Для Сатурна `beta_S` и `beta_E` — планетоцентрические широты подсолнечной и
поднаблюдательной точек. Определяется

```math
\beta=
\begin{cases}
\sqrt{|\beta_S\beta_E|}, & \beta_S\beta_E\ge0,\\
0, & \beta_S\beta_E<0.
\end{cases}
```

Опубликованная формула применяется только при `a < 6.5 градуса` и `beta <
27 градусов`:

```math
V_{Saturn}=-8.914+d-1.825\sin\beta+0.026a
-0.378\sin\beta\exp(-2.25a).
```

Для Урана планетоцентрическая широта переводится в планетографическую с
коэффициентом сжатия `f_U=0.0022927`; `beta_g` — среднее модулей
планетографических широт подсолнечной и поднаблюдательной точек:

```math
\beta_g=\frac{1}{2}\left(
\left|\arctan\frac{\tan\beta_{S,c}}{(1-f_U)^2}\right|
+\left|\arctan\frac{\tan\beta_{E,c}}{(1-f_U)^2}\right|
\right),
```

```math
V_{Uranus}=-7.110+d-0.00084\beta_g.
```

Формула Нептуна для земного наблюдателя не использует фазовое расширение,
предназначенное только для космических аппаратов. Для десятичного года `y`

```math
M_N(y)=\max\!\left(-7.00,
\min\!\left(-6.89,-6.89-0.0054(y-1980)\right)\right),
```

```math
V_{Neptune}=M_N(y)+d.
```

Для Плутона используется опорное значение JPL `V(1,0)=-1.0` без независимо
калиброванного фазового члена для земного наблюдателя:

```math
V_{Pluto}=-1.0+d.
```

Статус звёздной величины задаётся явно и зависит от тела. Меркурий, Уран и
Нептун используют `available`; Венера, Юпитер и Сатурн используют `available`
внутри опубликованных областей выше и `outside_published_model_domain` без
числа за их пределами. Марс и Плутон всегда используют
`planning_approximation` с конечным числом. Интерфейс обязан сохранять эти
различия. Для Марса применяется опубликованный базовый фазовый полином, но
намеренно опущены обе эмпирические поправки, зависящие от долготы,
`L(lambda_e)` и `L(L_s)`; рассчитанная ниже `L_s` остаётся отдельной сезонной
характеристикой и не подменяет отсутствующую поправку яркости. В указанной
статье приведены вращательные отклонения до примерно `0.06 mag`; изменение
яркости при пылевых бурях также не входит в эту модель. Для Плутона отсутствует
независимо калиброванный фазовый член земного наблюдателя, поэтому закон
расстояния с `V(1,0)` также явно называется планировочным приближением.

Ареоцентрическая солнечная долгота Марса следует [алгоритму NASA GISS
Mars24](https://www.giss.nasa.gov/tools/mars24/help/algorithm.html). При
`D=JDE-2451545.0`

```math
\begin{aligned}
M&=19.3871+0.52402073D,\\
\alpha_{FMS}&=270.3871+0.524038496D,\\
L_s&=(\alpha_{FMS}+C)\bmod360\ \mathrm{градусов},
\end{aligned}
```

где `C` — опубликованное уравнение центра с пятью гармониками и семью
планетными возмущениями Mars24. Северные сезоны соответствуют полуоткрытым
квадрантам `[0,90)`, `[90,180)`, `[180,270)` и `[270,360)` градусов.

Для каждого тела и каждых местных гражданских суток IANA, затронутых
прогнозом, суточная кульминация является максимумом той же функции
топоцентрической видимой высоты, которая используется для маркера:

```math
(t_{culm},h_{culm})=
\underset{t\in[t_{local\ midnight},t_{next\ local\ midnight})}{\mathrm{arg\,max}}
\ h_{app}(t).
```

Детерминированная реализация выполняет сканирование с шагом десять минут,
заключает наибольшую точку в скобку и уточняет её методом золотого сечения до
ширины скобки не более одной секунды. Из-за переходов времени гражданские
сутки могут содержать 23, 24 или 25 часов.

#### Полярная звезда и координаты SynScan

Полярная звезда является отдельным слоем только астрокупола с каталожным
идентификатором `polaris-simbad-revised-hipparcos-icrs-j2000-v1`.
Закреплённая строка [SIMBAD для Полярной
звезды](https://simbad.cds.unistra.fr/simbad/sim-id?Ident=Polaris) задаёт

```math
\alpha_0=02^{\mathrm h}31^{\mathrm m}49.09456^{\mathrm s},
\qquad
\delta_0=+89^{\circ}15'50.7923'',
```

```math
\mu_{\alpha *}=44.48\ \mathrm{mas\,yr^{-1}},
\qquad
\mu_\delta=-11.85\ \mathrm{mas\,yr^{-1}}.
```

Для SynScan показывается `02h 31m 49.095s`, `+89 градусов 15 минут 50.79
секунды` с явной подписью `ICRS/J2000.0`. Это округлённые каталожные, а не
текущие видимые координаты. Для отрисовки каталожный единичный вектор линейно
продолжается в касательной плоскости по `mu_alpha*` и `mu_delta`, нормируется,
прецессирует из J2000 на дату и переводится в горизонтальную систему по
среднему звёздному времени с той же планировочной рефракцией. Параллакс,
радиальная скорость, годичная аберрация, нутация и орбита кратной системы не
моделируются: это устойчивый планировочный маркер, а не прецизионная
астрометрия.

Затем вектор переводится в экваториальную систему J2000, после чего по
алгоритмам Меуса учитываются прецессия, нутация и годичная аберрация для
видимого положения на дату. Плутон рассчитывается отдельно по периодическому
ряду главы 37 книги Жана Меуса *Astronomical Algorithms*, реализованному в
закреплённом модуле `github.com/soniakeys/meeus/v3`. Солнце и Луна сохраняют
существующие солнечные и лунные ряды Меуса; для Луны до перехода к
горизонтальной системе учитывается топоцентрический параллакс.

Для прямого восхождения `alpha`, склонения `delta`, геоцентрического расстояния
`Delta`, геодезической широты WGS84 `phi` и местного часового угла `H`
топоцентрическое преобразование
использует `a=6378,137 км`, `f=1/298,257223563` и `e^2=f(2-f)`. Часовой угол равен

```math
H=\mathrm{GAST}(t_{UT1})+\lambda_{east}-\alpha.
```

Экваториальные координаты являются видимым положением, поэтому при вращении
используется гринвичское видимое звёздное время GAST с учётом нутации по
прямому восхождению, а не GMST. В рабочем процессе есть UTC, но нет оперативных
параметров вращения Земли, поэтому принимается `UTC приблизительно равно UT1`.
[IERS определяет
GAST](https://www.iers.org/iers/en/service/glossary/functions/glossary/G) как
гринвичский часовой угол истинной точки равноденствия и поддерживает
[`модуль UT1-UTC` меньше `0,9 с`](https://www.iers.org/SharedDocs/Glossareintraege/EN/C/utc?nn=ef326957-149a-433c-8880-5730bfcd389d).
Для современной системы UTC с 1972 года это соответствует менее чем
`0,0038 градуса` вращения Земли. Для более ранних сроков входная метка времени
считается UTC-подобным приближением UT1, и предел `0,9 с` для неё не заявляется.
Современная граница относится к угловому направлению; сам азимут становится
плохо обусловлен сколь угодно близко к зениту.

Далее вводятся радиус первого вертикала и нормированные компоненты положения
наблюдателя в ECEF:

```math
N(\phi)=\frac{a}{\sqrt{1-e^2\sin^2\phi}},
\qquad
\rho_c=\frac{N\cos\phi}{a},
\qquad
\rho_s=\frac{N(1-e^2)\sin\phi}{a},
\qquad
p=\frac{a}{\Delta}.
```

Далее

```math
A=\cos\delta\sin H,
```

```math
B=\cos\delta\cos H-\rho_c p,
```

```math
C=\sin\delta-\rho_s p,
```

```math
H'=\mathrm{atan2}(A,B),
\qquad
\delta'=\arcsin\!\left(\frac{C}{\sqrt{A^2+B^2+C^2}}\right).
```

Высота без рефракции и азимут от севера через восток равны

```math
h=\arcsin\!\left(
\sin\phi\sin\delta'+\cos\phi\cos\delta'\cos H'
\right),
```

```math
Az=\mathrm{atan2}\!\left(
-\cos\delta'\sin H',
\sin\delta'\cos\phi-\cos\delta'\cos H'\sin\phi
\right)\pmod{2\pi}.
```

Планировочная видимая высота использует принятую стандартную поправку
рефракции только при `h >= -1 градуса`; ниже этой границы она равна высоте без
рефракции:

```math
h_{app}=h+
\frac{0.0002967}
{\tan\!\left(h+\frac{0.00312536}{h+0.08901179}\right)}.
```

Эта поправка — **численное правило проекта** для стандартных условий, а не
измерение давления и температуры на площадке. В JSON сохраняются обе высоты,
поэтому различие не скрывается.

Между соседними точными почасовыми единичными направлениями браузер рисует
плавную пунктирную линию по кратчайшей дуге сферы. При `0 <= q <= 1` и
`theta=acos(clamp(u0 dot u1,-1,1))`

```math
\mathbf u(q)=
\frac{\sin((1-q)\theta)}{\sin\theta}\mathbf u_0+
\frac{\sin(q\theta)}{\sin\theta}\mathbf u_1.
```

Для отображения час делится на двенадцать пятиминутных отрезков. Сферическая
интерполяция относится **только к геометрии линии**: маркер выбранного часа и
подсказка используют точную сохранённую почасовую точку, а Overall и
метеоданные не интерполируются. Детерминированная большая окружность задаёт
полное поведение для математического случая противоположных направлений;
соседние реальные почасовые эфемериды противоположными не бывают.

JPL указывает для краткосрочных элементов пригодность для планирования и
наведения и номинальные ошибки гелиоцентрической долготы от `10` до `600`
угловых секунд в зависимости от планеты. Для высокоточной работы следует
использовать [JPL Horizons](https://ssd-api.jpl.nasa.gov/doc/horizons.html)
или актуальную интегрированную эфемериду DE. Независимая контрольная таблица
наблюдателя Horizons `AIRLESS` для `53.65 N, 37.3462 E` на
`2026-08-12 00:00 UTC` охватывает все десять тел. Наибольшее расхождение —
`0,0987 градуса` по азимуту Сатурна. Вторая проверка содержит тридцать
положений Марса—Плутона в пяти сроках с шагом три месяца от `2026-01-15` до
`2027-01-15`; максимумы равны `0,0856 градуса` по азимуту и `0,0662 градуса`
по высоте. Все шестьдесят отдельных сезонных компонент и все двадцать
компонент проверки десяти тел меньше фиксированного регрессионного предела
`0,15 градуса`. Запрос Horizons закрепляет `CENTER=coord@399`, точные
координаты наблюдателя на нулевой высоте, `TIME_TYPE=UT`, `QUANTITIES=4`,
`ICRF`, `AIRLESS`, `EXTRA_PREC=YES` и DE441. Эти проверки защищают от ошибок
знака, системы координат, времени, сезонного продолжения и перехода азимута
через ноль, но не являются глобальной калибровкой точности.
Фотореалистичные пиктограммы тел — сгенерированные элементы оформления; они
не кодируют угловой размер, ориентацию, фазу, яркость или масштаб. Эти
величины выводятся отдельно из описанных выше версионированных полей сервера.
